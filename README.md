# LoanMate 🏦  

Projet de Machine Learning visant à prédire l’éligibilité à un prêt bancaire à partir de données clients.  
Le notebook contient l’ensemble des étapes classiques d’un workflow ML :  

- 📊 **Exploration des données** : analyse descriptive et visualisation.  
- 🧹 **Prétraitement** : gestion des valeurs manquantes, encodage, normalisation.  
- 🤖 **Modélisation** : comparaison de plusieurs algorithmes de classification (Logistic Regression, Random Forest, etc.).  
- 📈 **Évaluation** : métriques de performance (accuracy, confusion matrix, etc.).  

## Installation  
Cloner le repo et installer les dépendances :  
```bash
git clone https://github.com/marwanbns/LoanMate
cd LoanMate
pip install -r requirements.txt
```

## Utilisation
Ouvrir le notebook et exécuter les cellules.
```bash
jupyter notebook LoanMate.ipynb
```
